## 📋 Sobre o Projeto

Este repositório contém minha página de currículo pessoal, criada com HTML e CSS puro.
O objetivo é ter um currículo online moderno, acessível pelo navegador, sem depender de plataformas externas.

## ✏️ Como Personalizar

1. Abra `index.html` e substitua os campos marcados com comentários:
   - **Nome**, **cargo/área**, **e-mail** e links de contato no `<header>`
   - **Sobre Mim** — escreva seu resumo profissional
   - **Experiência Profissional** — preencha cada `.card` com empresa, período e atividades
   - **Educação** — adicione sua formação acadêmica
   - **Habilidades** — liste suas competências técnicas e comportamentais
   - **Projetos** — destaque seus projetos pessoais ou profissionais
   - **Idiomas** — informe os idiomas que você fala e o nível
2. Substitua `avatar.jpg` pela sua foto de perfil.
3. Ajuste as cores no arquivo `style.css` — edite as variáveis em `:root` para trocar o tema.

---

## 🌐 Publicando com GitHub Pages

1. Vá em **Settings → Pages** neste repositório.
2. Em **Source**, selecione o branch `main` e a pasta `/ (root)`.
3. Clique em **Save**.
4. Em alguns minutos sua página estará disponível em `https://<seu-usuario>.github.io/MyPage`.
