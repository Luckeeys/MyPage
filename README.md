## Sobre o projeto

O **MyPage** é o currículo web de Lucas Cipriano, desenvolvedor Full Stack especializado em soluções de Contact Center e no ecossistema Genesys. Em vez de uma página estática, o projeto organiza a trajetória profissional como uma experiência visual: tecnologias, experiências, certificações e formação em uma interface clara, responsiva e interativa.

O resultado combina a objetividade de um currículo com os detalhes de uma aplicação front-end: tema claro e escuro, navegação fluida, carrossel de competências e microinterações que dão ritmo à leitura.

## Destaques

- Tema claro e escuro com persistência da preferência do visitante.
- Navegação responsiva para desktop e dispositivos móveis.
- Carrossel interativo para explorar as principais tecnologias.
- Cards expansíveis com detalhes de cada competência.
- Bordas e ícones com animações em gradiente no hover.
- Links diretos para currículo, e-mail, LinkedIn e GitHub.

## Tecnologias

| Camada | Ferramentas |
| --- | --- |
| Estrutura | HTML5 semântico |
| Estilo | CSS3, variáveis CSS, animações e layout responsivo |
| Interação | JavaScript puro |
| Conteúdo | Assets locais e currículo em PDF |

## Como executar

Não há dependências nem etapa de compilação. Basta abrir [index.html](index.html) em um navegador moderno.

Para uma experiência de desenvolvimento mais confortável, use uma extensão de servidor local, como o Live Server do VS Code.

## Estrutura

```text
.
├── assets/       # Logo, foto de perfil, ícones e currículo
├── index.html    # Estrutura e conteúdo do portfólio
├── styles.css    # Temas, responsividade e animações
└── script.js     # Navegação, carrossel e interações
```
